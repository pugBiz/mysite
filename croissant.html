CroissantWatcher

A personal Reddit watcher that searches Reddit for posts and comments mentioning "bake croissants".

Purpose

This application is a small single user script that periodically searches Reddit for the keyword bake croissants and notifies the owner via a configured notification channel. It is intended for personal noncommercial use and only reads public Reddit content.

How it works

Type: Script
Search scope: public Reddit posts and comments (keyword: bake croissants)
Runs: scheduled via GitHub Actions using a single Reddit account

The app authenticates using a Reddit Script app and calls Reddit's OAuth endpoints to search for new matches. Matches are delivered to the repository owner via the configured notification channel such as a Discord webhook or email.

Privacy and data handling

No private data is stored or published by this page. The bot only reads public Reddit content. Credentials such as client secret and account password must be stored securely as GitHub repository secrets and must not be committed to the repository.
